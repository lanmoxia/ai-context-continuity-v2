## 已确认 Findings

### F55-WORK-0002-01 — high — `validate()` 在 Source Fingerprint 引用路径上抛 traceback

证据：

- `src/continuity/schemas/common.schema.json:44` 和 `:67` 在 common schema 内使用 `#/$defs/...` 本地引用。
- `src/continuity/schemas/registry.py:76` 使用 `jsonschema.validators.RefResolver`，`registry.py:126` 直接 `list(validator.iter_errors(instance))`，未把引用解析错误转换为稳定结构化错误。
- 5.5 复现：调用 `validate("checkpoint", instance)`，其中 `source_fingerprint.untracked_files` 含 `{path, sha256}`，实际抛出 `jsonschema.exceptions._RefResolutionError: unknown url type: ''` 并打印 traceback。

违反：

- WORK-0002 验收要求 Schema 失败时返回稳定排序的结构化错误，且不得打印 traceback。
- WORK-0002 要求外部 URI `$ref` 和未登记本地文件引用在任何网络或项目文件读取前被拒绝。

修复要求：

- registry 必须对固定白名单 schema 的 `$ref` 做显式预扫描和解析边界校验，只允许内置固定 URN 及其片段，必要时支持 common 内部片段的正确离线解析。
- `validate()` 对非法实例必须返回结构化错误列表，不得因引用解析失败向调用者泄漏 traceback。
- 增加回归测试覆盖非空 Source Fingerprint、引用解析失败路径、外部 URI `$ref`、未登记本地/文件引用，并证明拒绝发生在任何网络或项目任意文件读取前。

### F55-WORK-0002-02 — high — 持久时间不是 RFC 3339，只是宽松正则

证据：

- `src/continuity/schemas/common.schema.json:17-20` 的 `rfc3339_with_timezone` 只有形状正则。
- 5.5 复现：`validate("task", {..., "created_at": "2026-99-99T99:99:99+99:99", ...})` 返回 `[]`。

违反：

- WORK-0002 验收要求所有持久时间必须是带时区的 RFC 3339，非法值被拒绝。
- WORK-0002 known constraints 要求格式校验必须显式启用，不能只依赖 jsonschema 默认未启用的 format 行为。

修复要求：

- Schema 与 registry 必须结合使用明确启用的格式校验或等价严格校验，拒绝不存在的日期、时间和时区偏移。
- 增加非法日期、非法时间、非法时区、无时区和合法 `Z`/offset 的测试。

### F55-WORK-0002-03 — high — 引用字段和哈希字段过宽，非法 ID/哈希被接受

证据：

- `src/continuity/schemas/current.schema.json:10-18` 把多个实体引用字段定义为 `string|null`，未使用稳定 ID 约束。
- `src/continuity/schemas/review-pack.schema.json:11` 的 `stage_id`、`:17` 的 `stage_sha256`、`:43` 的 `source_fingerprint_sha256` 也未精确约束。
- 5.5 复现：`validate("current", {... "active_task_id": "not-a-stable-id", "active_work_order_id": "x", ...})` 返回 `[]`。
- 5.5 复现：`validate("review-pack", {... "stage_id": "not-stable", "stage_sha256": "not-a-sha", "source_fingerprint_sha256": "bad", ...})` 返回 `[]`。

违反：

- WORK-0002 验收要求稳定 ID 使用固定大写前缀和至少四位十进制编号。
- WORK-0002 验收要求引用字段、Source Fingerprint 结构和哈希字段由 Schema 精确约束。

修复要求：

- 所有实体引用字段应按已明确规格使用稳定 ID 约束；允许 `null` 的字段也必须在非 null 时约束为稳定 ID。
- 所有 SHA-256 字段应在非 null 时约束为小写 64 位十六进制。
- 增加 current、context-pack、review-pack、review-decision 等引用字段和 hash 字段的非法 fixture 或 inline 测试。

### F55-WORK-0002-04 — high — Source Fingerprint 结构缺少未跟踪文件大小

证据：

违反：

- WORK-0002 required output 要求 common schema 提供 Source Fingerprint 共享定义。
- WORK-0002 验收要求 Source Fingerprint 结构由 Schema 精确约束。

修复要求：

- 在 Source Fingerprint 未跟踪文件条目中加入 `size_bytes`，并设为必填非负整数。
- 更新相关 fixtures 和 tests，确保缺失 size、负数 size、错误类型被拒绝。
