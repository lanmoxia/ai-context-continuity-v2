# AI Context Continuity V2

这是一个面向个人 AI 编程工作的本地会话接力工具。

当开发或审核任务跨越多个 AI 窗口时，新窗口通过项目文件恢复当前任务、进度、验证结果和下一步，不依赖旧聊天记录。

核心能力：

- 大任务分阶段。
- 工作进度检查点。
- 新旧窗口接力。
- 审核材料和代码版本绑定。
- 中断恢复、并发保护和路径安全。
- 控制新窗口需要读取的内容量。

## 文档入口

- `docs/README.md`：文档用途和读取边界。
- `docs/spec/`：产品与技术规格。
- `docs/planning/`：项目所有者使用的计划和未确认决定。
- `docs/document-registry.json`：机器可读的文档分类和准入状态。

## 上下文原则

不要让任何 AI “读取全部文档”。每个任务必须通过上下文清单列出允许读取的文件。`docs/planning/`、聊天摘要、被否决方案和无关历史记录默认禁止进入开发、审核或恢复上下文。

工具负责可靠保存事实和生成最小上下文包，不负责选择模型或控制外部客户端。
